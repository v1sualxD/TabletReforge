# TabletReforge

Plugin indépendant dérivé de TabletHelper, avec filtres de conservation et reforge des rejets.
Consulter ../../README.md et ../../AUTOREFORGE-FR.md pour la compilation et l'installation.
Les noms internes TabletHelper sont conservés ; le plugin installé porte l'identifiant TabletReforge.
Sources expérimentales : compilation et validation en jeu à effectuer.
