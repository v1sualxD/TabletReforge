## TabletReforge 1.1.0

Maintenance release preparing the repository for ongoing development.

- Cleaner settings and current English documentation.
- One central version definition and one automated build/release workflow.
- Removed obsolete highlight data and unused settings.
- Added regression tests for inventory comparison and transfer expectations.
- Existing stash, reforge, full-bag deposit and timing behavior is retained from 1.0.3.

Install using the repository URL in POEFixer's plugin manager. TabletReforge.zip contains the required Plugins/TabletReforge/TabletReforge.dll layout.

The return-to-stash step deposits every item in the bag, not only tablets. Stash routing and available capacity still apply.

Automated build and tests are required before publication. This release does not claim a newly verified complete live-game cycle.
